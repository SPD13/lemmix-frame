SETTINGS BACKUP

Save the headset's settings on this computer, or bring a saved file back. The files are the web version's too.

A level pack is a folder: upload the whole folder, or its .zip and press install next to it (the zips of NeoLemmix and its styles install the same way).

The headset's library and settings update when an upload, a delete or a settings file is done. This page only works while the web server is turned on in the app's setup page.

# Steam library artwork

Made by `tools/art/make-art.sh` (with the boot splash), from the NeoLemmix title screen's art as
the newer releases draw it: the dirt background tiled with a warm glow and darkened edges, the
NeoLemmix logo, and "STEAM FRAME EDITION" in Superclarendon Black, yellow with the logo's dark
green outline.

| File | Size | Steamworks slot |
|---|---|---|
| `capsule.png` | 600 x 900 | Library capsule (the logo, the subtitle, and a lemming holding up a "VR" sign) |
| `header.png` | 920 x 430 | Library header / header capsule |
| `hero.png` | 3840 x 1240 | Library hero: the dirt alone, no text (Steam lays the logo over it) |
| `logo.png` | 1280 x 720 | Library logo: the logo and the subtitle on a transparent background |

The logo, the background and the sign are NeoLemmix's artwork (their creators keep all rights;
NeoLemmix's licence allows their use "only for the purpose of running NeoLemmix"), used here at
the project owner's decision.

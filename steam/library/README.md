# Steam library artwork

Made by `tools/art/make-art.sh` (with the boot splash), from the NeoLemmix title screen's art as
the newer releases draw it (and, for the hero, the `orig_dirt` style and the default lemmings): the dirt background tiled with a warm glow and darkened edges, the
NeoLemmix logo, and "STEAM FRAME EDITION" in Superclarendon Black, yellow with the logo's dark
green outline.

| File | Size | Steamworks slot |
|---|---|---|
| `capsule.png` | 600 x 900 | Library capsule (the logo, the subtitle, and a lemming holding up a "VR" sign) |
| `header.png` | 920 x 430 | Library header / header capsule |
| `hero.png` | 3840 x 1240 | Library hero, no text (Steam lays the logo over it): a small Dirt level at 10x on the dirt - the `orig_dirt` terrain and trapdoor and exit, NeoLemmix's default lemmings at work (falling, walking, blocking, building, digging, bashing, climbing, floating, leaving) |
| `logo.png` | 1280 x 720 | Library logo: the logo and the subtitle on a transparent background |

The logo, the background, the sign, the terrain and the lemmings are NeoLemmix's artwork (the
Dirt style and the lemmings DMA Design's) (their creators keep all rights;
NeoLemmix's licence allows their use "only for the purpose of running NeoLemmix"), used here at
the project owner's decision.
